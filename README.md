# 이북 스크린샷 도구

이 저장소는 전자책(E-book)을 캡처하고 두 페이지로 나뉜 이미지를 분할하는 두 가지 Python 스크립트를 포함하고 있습니다. 이 도구는 전자책을 이미지 형태로 백업하거나 특정 페이지를 추출하는 데 유용합니다.

## 파일 구조

- `capture.py` - 전자책 페이지를 자동으로 캡처하는 스크립트
- `split2page.py` - 두 페이지 이미지를 개별 페이지로 분할하는 스크립트

## 요구 사항

```
pip install pyautogui
pip install pillow
pip install pyperclip
```

## capture.py

전자책 뷰어 앱에서 페이지를 자동으로 캡처하는 스크립트입니다.

### 특징
- 지정된 시작 페이지부터 종료 페이지까지 순차적으로 캡처
- 랜덤 지연 시간을 추가하여 자연스러운 동작 구현
- 파일명 자동 생성 (예: '머신러닝_0465.png')
- 캡처 후 자동으로 다음 페이지로 이동

### 사용법

1. 변수 설정:
   ```python
   start_page = 465     # 시작 페이지 번호
   total_page = 780     # 전체 페이지 수
   book_name = '머신러닝' # 책 이름 (파일명 접두어로 사용)
   capture_pos = (144, 200)          # 캡처 버튼 위치 (x, y)
   ebook_screen_center_pos = (2500, 900) # 전자책 화면 중앙 위치 (x, y)
   const_sleep_time = 0.2            # 기본 지연 시간(초)
   ```

2. 스크립트 실행:
   ```
   python capture.py
   ```

3. 실행 시 주의사항:
   - 스크립트를 실행하기 전에 전자책 뷰어가 열려있어야 함
   - 실행 후 3초 지연 시간이 있으므로 전자책 뷰어를 활성화된 창으로 설정
   - 모든 좌표는 당신의 화면 해상도에 맞게 조정해야 함

## split2page.py

두 페이지가 하나의 이미지로 캡처된 경우, 이를 개별 페이지로 분할하는 스크립트입니다.

### 특징
- 폴더 내 모든 PNG 파일 처리
- 이미지를 좌/우 페이지로 정확히 분할
- 원본 파일명을 유지하면서 접미어 추가 (예: '머신러닝_0465_1.png', '머신러닝_0465_2.png')
- 오류 처리 및 로깅 기능

### 사용법

1. 폴더 설정:
   ```python
   input_folder = "input"   # 원본 이미지가 있는 폴더
   output_folder = "output" # 분할된 이미지가 저장될 폴더
   ```

2. 스크립트 실행:
   ```
   python split2page.py
   ```

## 워크플로우 예시

1. `capture.py`를 사용하여 전자책의 모든 페이지를 캡처
2. 캡처된 이미지를 `input` 폴더에 배치
3. `split2page.py`를 실행하여 두 페이지 이미지를 개별 페이지로 분할
4. 분할된 이미지는 `output` 폴더에서 확인

## 주의사항

- 이 스크립트는 개인적인 백업 목적으로만 사용해야 합니다.
- 저작권이 있는 자료의 무단 배포는 법적 문제를 일으킬 수 있습니다.
- 스크립트 실행 중에는 마우스와 키보드를 사용하지 마세요.
- 화면 해상도, 전자책 뷰어 프로그램에 따라 좌표값 조정이 필요할 수 있습니다.

## 문제 해결

- 캡처 위치가 정확하지 않은 경우: `capture_pos`와 `ebook_screen_center_pos` 값을 조정
- 지연 시간이 부족한 경우: `const_sleep_time` 값을 증가
- 분할된 이미지가 정확하지 않은 경우: 특정 전자책 뷰어에 맞게 `split_two_page_image` 함수 내의 이미지 분할 로직을 수정
